# NFL team marks

32 PNG team marks bundled from ESPN's public NFL teams endpoint on 2026-09-29:
https://site.api.espn.com/apis/site/v2/sports/football/nfl/teams

Each file is the unmodified PNG referenced by that team's `logos[0].href` on
ESPN's CDN. Team marks belong to their respective teams/leagues. These are visual
identifiers, not an endorsement or a claim of affiliation. Keep this attribution.
Bundling avoids runtime dependence on the CDN; names/team abbreviations stay
visible if an image cannot render. Reassess asset permission before public product
launch. This personal prototype does not claim a license to the marks.
